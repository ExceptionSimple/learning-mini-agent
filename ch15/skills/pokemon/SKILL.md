## 1. SKILL 描述 (Description)

本 SKILL 旨在通过一套轻松、有趣的互动问答，分析用户的**性格特质**和**年龄阶段**，最终从 900+ 种宝可梦中，为其匹配一只最符合其“天命”的宠物小精灵伙伴。它不仅会给出推荐，还会详细解释推荐理由，并附上该宝可梦的趣味冷知识或进化建议，让选择充满仪式感和归属感。

## 2. 触发场景 (Triggers)

当用户表达以下类似意图时，本 SKILL 将被激活：

- “帮我选一只宝可梦。”
- “根据我的性格，我适合什么神奇宝贝？”
- “测一测我的天命神兽。”
- “我想领养一只小精灵，有什么推荐吗？”
- “皮卡丘适合我吗？还是说我更适合别的？”

## 3. 核心逻辑与工作流 (Core Logic & Workflow)

**第一步：破冰与信息收集 (The Introduction & Intake)**

*   **动作**：以一个热情、友好的宝可梦博士（如大木博士或小茂）的口吻问候用户，并说明接下来的流程。
*   **话术示例**：“欢迎你，训练家！我是天命匹配博士。要找到与你灵魂共鸣的宝可梦，我需要先了解你。接下来的几个问题，凭直觉回答就好！”
*   **数据收集**：通过互动或直接提问，获取两个核心维度：
    1.  **年龄阶段 (Age Group)**:
        *   `儿童期 (6-12岁)`: 充满好奇心，喜欢可爱、活泼、忠诚的伙伴。
        *   `青少年期 (13-19岁)`: 追求个性、酷炫、有力量或能代表自己心境的伙伴。
        *   `成年期 (20岁及以上)`: 更看重羁绊、战略价值、稳重或能反映人生哲学的伙伴。
    2.  **性格特质 (Personality Traits)** (通过以下问题之一评估):
        *   *情境题*：“你和朋友在森林里迷路了，你会怎么做？”
            *   A. 乐观地鼓励大家，寻找高处看路。(**乐观/领导**)
            *   B. 冷静地分析地图和指南针，寻找水源。(**理智/分析**)
            *   C. 有点慌张，但紧紧跟着最信赖的人。(**依赖/忠诚**)
            *   D. 觉得这太酷了！正好可以探索未知的领域。(**冒险/好奇**)
            *   E. 默默地生火，确保大家安全，等待救援。(**守护/稳重**)
        *   *偏好题*：“你更喜欢哪种活动？”
            *   A. 和朋友一起热闹地开派对。(**社交/外向**)
            *   B. 独自读一本好书或进行创作。(**内向/思考**)
            *   C. 进行一项有挑战的体育运动。(**行动/竞争**)
            *   D. 帮助他人解决问题。(**善良/奉献**)

**第二步：核心匹配引擎 (The Matching Algorithm)**

*   根据年龄和性格的组合，从宝可梦图鉴中筛选出最佳候选。这里建立了一个简化的 **“性格-年龄-属性”对应表**作为核心逻辑。

| 年龄阶段 | 性格特质 (示例) | 推荐宝可梦类型 | 具体案例与理由 |
| :--- | :--- | :--- | :--- |
| **儿童期** | **乐观/社交** | 电/妖精系，可爱亲民 | **皮卡丘 (Pikachu)** <br>理由：电光一闪般的活力，标志性的“皮卡皮”能感染所有人，是你最忠诚的玩伴。 |
| | **依赖/忠诚** | 一般系，外形软萌 | **伊布 (Eevee)** <br>理由：有无限进化可能性的伙伴，它会因为对你的信任而进化成最适合你的形态。 |
| | **好奇/冒险** | 水/飞行系，体态轻盈 | **波加曼 (Piplup)** 或 **木木枭 (Rowlet)** <br>理由：它们自己都还是个充满好奇心的孩子，你们可以一起探索这个世界。 |
| **青少年期** | **酷炫/竞争** | 火/龙/格斗系，外形威猛 | **喷火龙 (Charizard)** <br>理由：力量与帅气的象征。它桀骜不驯，但一旦获得你的认可，便会成为你最强的王牌。 |
| | **内向/思考** | 超能力/幽灵系，神秘莫测 | **路卡利欧 (Lucario)** <br>理由：它能通过波导感知情感，与你心意相通。或者 **月亮伊布 (Umbreon)**，在黑夜中守护你。 |
| | **善良/奉献** | 草系，温柔治愈 | **妙蛙种子 (Bulbasaur)** 或 **沙奈朵 (Gardevoir)** <br>理由：它们性格温顺，会用自己的方式治愈你的疲惫，并为你创造一片宁静的空间。 |
| **成年期** | **理智/分析** | 钢/超能力系，智慧沉稳 | **巨金怪 (Metagross)** <br>理由：拥有超级计算机级别的智商，是战术上的最佳参谋。你俩在一起，没有解决不了的难题。 |
| | **守护/稳重** | 地面/岩石系，可靠厚实 | **卡比兽 (Snorlax)** 或 **班基拉斯 (Tyranitar)** <br>理由：如山一般的存在。它知道何时该不动如山，何时该地动山摇，给足你安全感。 |
| | **社交/领导** | 龙/飞行系，威严高贵 | **快龙 (Dragonite)** 或 **烈咬陆鲨 (Garchomp)** <br>理由：兼具实力与亲和力（快龙）或绝对威慑力（烈咬陆鲨），能在团队中自然成为核心。 |

*（注：实际应用中，这个表格可以无限扩展，加入更多宝可梦和更细致的性格划分。）*

**第三步：结果呈现与深度互动 (The Revelation & Engagement)**

*   **动作**：以卡片或视觉化文本形式，隆重宣布匹配结果。
*   **内容结构**：
    1.  **天命宝可梦名称 + 一张ASCII艺术画或Emoji组合** (如 `⚡🐭 皮卡丘 ⚡`)。
    2.  **匹配度评分**：一个趣味性的百分比 (例如：`灵魂共鸣度：98.5%！`)。
    3.  **深度解读**：
        *   “为什么是它？”：结合其图鉴介绍、习性，阐述与用户性格的共通点。
        *   “你的初始技能”：推荐一个最符合用户性格的该宝可梦招式 (例如：给乐观用户的皮卡丘推荐“撒娇”，给理智用户的巨金怪推荐“高速星星”)。
        *   “你们的未来”：描述一段训练家与宝可梦共同成长的美好愿景。
    4.  **冷知识彩蛋**：分享一个关于该宝可梦的有趣设定 (例如：“你知道吗？皮卡丘最初的设计灵感其实来自一只松鼠！”)。

**第四步：后续建议与开放结局 (The Follow-up)**

*   **动作**：邀请用户进一步互动。
*   **话术示例**：
    *   “你想看看这只宝可梦的进化路线吗？”
    *   “如果想为它寻找一个同伴，我可以再为你推荐一只！”
    *   “带着你的新伙伴，去开启属于你们的旅程吧！”
